# Carco's Chaos Edition for Dusklight

Experience Dusklight like it's your worst nightmare!

## Featuring:
- ### 4 Challenge effects (with more on the way!)
  - Super-speed
  - Invisibility
  - Constant Slipperiness
  - Randomized Controls
- ### Shuffle Mode!
  - With a customizable timer!

# Installation Steps:
1. Download the latest release
2. Extract the .dusk file from the downloaded zip
3. Place the .dusk file in your mods folder for dusklight
4. Have fun!

# Why "Carco's" Chaos Edition?
I don't want this to be the only chaos-type mod for the game, and therefore don't want to
single-handedly claim the name of just "Chaos Edition"
